# Origin Hotel — Mehmonxona Boshqaruv Tizimi va Landing Page

Zamonaviy mehmonxona veb-sayti va to'liq ma'muriy boshqaruv tizimi (React 19 + TypeScript + Tailwind CSS v4 + Vite).

## Asosiy imkoniyatlar

- 🏨 **Asosiy Landing Page (`/`)**: Xonalar katalogi, onlayn tezkor bron qilish vidjeti, qulayliklar va mijozlar sharhlari
- 🔐 **Autentifikatsiya (`/login`)**: Demo hisoblar (Admin, Manager, Staff), rolga asoslangan kirish
- 📊 **Boshqaruv Paneli (`/admin`, `/staff`)**:
  - **Dashboard**: Asosiy statistik ko'rsatkichlar, bandlik darajasi, so'nggi bronlar
  - **Xonalar**: Xonalar kartochkalari, status filtrlari va narxlar
  - **Mehmonlar**: Mehmonlar ro'yxati, qidiruv va ma'lumotlar
  - **Bronlar**: Bronlar jadvali, statuslar (Kutilmoqda, Tasdiqlangan, Bekor)
  - **Moliya**: Daromad va xarajatlar tahlili, sof foyda
  - **Hisobotlar**: Oylik statistika va eksport
  - **Sozlamalar**: Mehmonxona va profil ma'lumotlari

## Ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dasturni ishga tushirish
npm run dev

# Ishlab chiqarish (production) uchun yig'ish
npm run build
```

## Texnologiyalar

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Router**: React Router DOM v7
- **Build tool**: Vite 8
